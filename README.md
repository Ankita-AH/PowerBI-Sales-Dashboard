# Business Problem

Organizations often collect large volumes of sales data but struggle to extract meaningful insights from it. Without interactive reporting, identifying profitable regions, seasonal trends, and customer purchasing behavior becomes time-consuming.

This project addresses these challenges by creating an interactive dashboard that enables users to monitor business performance and make informed decisions.

---

# Objectives

- Analyze sales performance
- Track monthly profit trends
- Compare state-wise sales
- Identify profitable product categories
- Analyze payment preferences
- Monitor key business KPIs

---

# Dataset

The project uses two datasets.

### Orders Dataset

Contains customer order information including:

- Order ID
- Order Date
- Customer Name
- State
- Payment Mode

### Details Dataset

Contains product information including:

- Category
- Sub Category
- Quantity
- Sales Amount
- Profit

---

# Dashboard Features

### KPI Cards

✔ Total Profit

✔ Total Quantity Sold

✔ Average Sales Amount

### Visualizations

- Quantity by Category
- Profit by Month
- Total Sales by State
- Quantity by Payment Mode
- Profit by Sub-Category

### Interactive Filters

- Quarter
- State

---

# Key Business Insights

- Maharashtra generated the highest sales revenue.
- Clothing contributed the largest quantity sold.
- Printers produced the highest profit.
- November recorded the maximum monthly profit.
- COD and UPI were the most frequently used payment methods.
